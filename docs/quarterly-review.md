# Revue trimestrielle / Quarterly review

Le slop change vite : ce qui était original il y a six mois est devenu un réflexe des modèles. Chaque trimestre (1er janvier, avril, juillet, octobre), une issue « Revue trimestrielle » s'ouvre automatiquement. Elle se traite ainsi :

1. **Tics** : relire les issues `tic`. Un tic entre dans `tells.md` quand il apparaît dans au moins deux pages générées sans lien entre elles. Il est daté, dans une nouvelle vague, avec une méthode à la place, jamais une police ou une couleur de remplacement.
2. **Polices réflexes** : une police vue dans deux projets générés sans lien entre dans `typography.md` §1 et sort de `font-catalog.md`. Vérifier les noms et licences restants.
3. **Sites modèles** : ouvrir chaque site de `site-models.md`. Retirer ceux qui ont changé de design, sont hors ligne ou sont devenus très copiés. Ajouter les issues `site-modele` dont la qualité à emprunter est concrète et vérifiée.
4. **Archétypes et tirage** : regarder les journaux de direction partagés ; un archétype ou une carte qui revient trop baisse de poids dans `roll.mjs`.
5. **Évaluation** : relancer les 5 briefs de `evals/` avec la nouvelle version, faire juger à l'aveugle, publier les scores dans `evals/README.md`. Une règle qui ne fait monter aucun score est candidate à la suppression.
6. **Publication** : entrée dans les Nouveautés du README, `.skill` reconstruit, édition anglaise mise à jour.

Every quarter an issue opens automatically; the same steps apply: tells, reflex fonts, model sites, roll weights, evaluation, release (FR and EN editions).
