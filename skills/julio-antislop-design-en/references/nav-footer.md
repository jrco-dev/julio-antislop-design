# Navigation and footer: the possible patterns

A generated page almost always has the same navigation (logo on the left, 4 links in the center, button on the right, sometimes in a blurred floating pill) and the same footer (4 columns of links, or the brand name set huge). This catalog lists the patterns that really exist online, with the case each one serves. Choose **from the content and the visitor's task**, never from habit.

Sources consulted on November 3, 2026: [navbar.gallery](https://navbar.gallery) (and its article on navigation bar types), [footer.design](https://www.footer.design) by NOOON Studio (categories: typographic, small text, illustrated, grid, flat, animated, cards, light, dark, big text), [unsection.com](https://www.unsection.com/category/footer-section-design) (footers classified by function: site links, sign-up, contact, social, closing). The examples cited come from these galleries; open them before drawing on them, because a site changes.

## Choose in three questions

1. **How many destinations?** 1 to 5: simple bar. 6 to 15: dropdown menus. More than 15, or several audiences: mega menu or sidebar.
2. **What is the visitor doing?** Deciding (Persuade): navigation steps back in favor of the argument and the action. Working (Operate): it stays visible and says where they are. Reading (Read): it gives the outline and the position. Discovering a work (Experience): it can become part of the work, without hiding the essentials.
3. **What should they find when they reach the bottom of the page?** The answer decides the footer.

## Navigation: 18 patterns

| # | Pattern | When | Rules | Real example |
| --- | --- | --- | --- | --- |
| N1 | **Simple bar** (name, 3 to 5 links, one action) | Default in Persuade | "Sign in" as a plain link; the action is the same as the page's | Align UI (navbar.gallery) |
| N2 | **Minimal bar** (name and one action, or name alone) | Short single-goal page, calm portfolio | No link that leads away from the argument | |
| N3 | **Sticky bar that hides** on scroll down and comes back on scroll up | Long pages on mobile | Reduced height once stuck; never a layout jump | |
| N4 | **Transparent over the hero, opaque afterward** | Full-bleed image hero | Contrast checked on the image (A1); switch without flicker | |
| N5 | **Dropdown menu** (one level of sub-links) | 6 to 15 destinations | Opens on click and keyboard, not only on hover; one column per menu | Clerk (navbar.gallery) |
| N6 | **Mega menu** (named columns, sometimes a highlight) | Large catalogs, several products or audiences | Columns by task or by audience, not by org chart; a single real highlight | Evervault (navbar.gallery) |
| N7 | **Audience choice** ("Personal / Business") at the top | Two audiences with different journeys | The choice changes the whole navigation, not just one link | |
| N8 | **Product sub-navigation** sticky under the main bar (product name, 3 or 4 sections, action) | Long product page within a larger site | Two bars at most; the main one can collapse when the sub-navigation sticks | |
| N9 | **Sidebar** (links, collapsible sections) | Docs, apps, dashboards | Current position marked; collapsible; drawer on mobile | Supabase (navbar.gallery) |
| N10 | **Search first** (field or ⌘K command palette) | Docs, apps, large content | Shortcut shown; keyboard-navigable results; search actually wired up | Notion (navbar.gallery) |
| N11 | **Bottom tab bar** (3 to 5 tabs) | Mobile app, PWA | Icon and label; obvious active tab; never in addition to a hamburger menu | |
| N12 | **Sticky reading outline** (table of contents that follows the reading) | Long articles, docs | Current section highlighted; hidden below 1024 px or collapsed into a menu | |
| N13 | **Breadcrumb** | Deep hierarchies: catalog, docs, admin | A complement, never the only navigation; last item not clickable | |
| N14 | **Steps / progress** | Checkout funnel, sign-up, onboarding | Number of steps announced; a way back; main navigation removed during the funnel | Cal.com (navbar.gallery) |
| N15 | **Announcement banner** above the bar | A real, dated piece of news (launch, closure, stock-out) | One sentence, dismissible, removed after the date; never permanent | RRE Ventures (navbar.gallery) |
| N16 | **Full-screen menu** | Experience, studios, few links to stage | Visible to the keyboard, obvious close, focus trapped in the open menu; never the only option on desktop in Persuade or Operate | RRE Ventures (navbar.gallery) |
| N17 | **Edge or vertical navigation** (links on one side or in a corner) | Portfolios, galleries, Experience | Legible and clickable at 24 px minimum; logical keyboard order | |
| N18 | **In-content navigation** (project index, table of contents at the top, anchor links) | Portfolios, one-pagers, editorial | The page is the navigation: the bar can shrink to the name | |

**Mobile**: each pattern has its mobile form written down (drawer, bottom tabs, reduced bar), never a hamburger by default if 3 links fit in the clear.

**Avoid**: blurred floating pill by reflex; 7 links and 2 buttons of equal weight; hamburger on desktop for no reason; mega menu for 8 links; permanent announcement banner; navigation that covers the headline on scroll.

## Footer: 15 patterns

The footer is a designed ending (`persuade.md`): it answers "what now?" for the visitor who has reached the bottom.

| # | Pattern | When | Content | Real example |
| --- | --- | --- | --- | --- |
| F1 | **One line** (name, legal notices, contact) | Short page, calm portfolio, app | The bare minimum, small text | |
| F2 | **End of argument**: the action one last time, large, then one line | Single-goal landing | The same action as the page, the proof or the price recalled in one sentence | "Closing links" on unsection.com |
| F3 | **Local practical info**: address, opening hours, phone, map, directions | Shops, restaurants, workshops, venues | Today's hours highlighted, the directions link, the clickable phone number | |
| F4 | **Direct contact**: an email address or a short form | Studios, freelancers, B2B | A single contact channel, large; response time if it is real | HelloHello (unsection.com) |
| F5 | **Sitemap in columns** | Large sites, multiple products, B2B | Columns by visitor task; legal notices and language at the bottom | Voiceflow, Pleo (unsection.com) |
| F6 | **Service footer** (shipping, returns, payment, help) | E-commerce | The real conditions in one line each, links to the details | |
| F7 | **Sign-up** to a newsletter or waitlist | Media, brands with a real publication | What you receive and how often; a single field | Concourse, Radian (unsection.com) |
| F8 | **Colophon**: credits, fonts, tools, last-updated date | Portfolios, editorial, designer and developer sites | The real sources (this is also A3 traceability made visible) | |
| F9 | **Event**: dates, venue, tickets | Festivals, conferences, exhibitions | The date and the booking action first | Pioneer by Fin (unsection.com) |
| F10 | **Live data**: local time, service status, last update | Studios, apps, media, if the information is real and useful | Computed live, never hard-coded | Le Punch (footer.design, via Abduzeedo) |
| F11 | **Illustrated**: a drawing or object from the subject closes the page | Brands with a strong world | A single element, drawn from the inventory, never decorative | Good Fella (footer.design, via Abduzeedo) |
| F12 | **Big text**: a sentence (not the name) set very large | Studios, Experience, when the sentence is the idea | A sentence that says something; the giant name remains a tell (`tells.md`) | Make-Believe (footer.design, via Abduzeedo) |
| F13 | **Solid color**: a flat fill from the palette that closes the page | Brands with a strong color | Contrast checked; same content as another pattern | Nabhi Shah (footer.design, via Abduzeedo) |
| F14 | **Language and region** | Multilingual sites, international commerce | Explicit selector, each language named in itself | |
| F15 | **App footer**: version, service status, help, shortcuts | Operate mode | Discreet, useful for support | |

You can **combine two patterns** at most (for example F2 then F1, or F3 and F7), never stack four blocks.

**Avoid**: 4 columns of links on a 5-section landing; giant brand name by reflex; social media icons with no real account behind them; "© 2026 — All rights reserved" as the only content of a page that had an action; newsletter with no real publication.

## In the report

Write down the navigation pattern and the footer pattern chosen (for example "N8 + N3, F3 + F1") with the reason in one line. Vary from one project to the next: they count toward the "structure" axis of the directions log.
