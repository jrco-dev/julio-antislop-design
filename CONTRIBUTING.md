# Contribuer / Contributing

Merci de vouloir améliorer le skill. Le slop change vite : une communauté le suit mieux qu'une seule personne.

## Ce qui aide le plus

1. **Un cas raté** : une page faite avec le skill qui « fait IA ». Issue « Page qui fait IA », avec le brief exact, l'agent, le modèle et des captures. C'est la contribution la plus utile.
2. **Un nouveau tic** : un procédé que les pages générées répètent, avec deux exemples sans lien. Issue « Nouveau tic repéré ».
3. **Un site modèle** : un site réel dont le design vient de son sujet, avec la qualité précise à emprunter. Issue « Site modèle à ajouter ».
4. **Une ressource** (police, bibliothèque, outil) avec sa licence vérifiée.

## Règles pour une modification

- **Rien d'inventé** : chaque police, composant, site ou chiffre ajouté a une source réelle vérifiée (plancher A3).
- **Une méthode, pas un style** : une règle ne propose jamais une police ou une couleur de remplacement « anti-slop » ; elle deviendrait le tic suivant.
- **Hiérarchie des sources** en cas de conflit : normes et accessibilité, puis honnêteté, puis contexte du mode, puis données mesurées, puis consensus entre sources, puis récence, puis goût.
- **Court** : `SKILL.md` reste sous 10 Ko ; le détail va dans `references/`, chargé seulement quand il sert.
- **Mesuré** : une règle qui change le comportement se teste sur les briefs de `evals/` avant et après ; joindre les scores à la pull request.
- **Deux éditions** : toute modification du français (`skills/julio-antislop-design`) se reporte dans l'anglais (`skills/julio-antislop-design-en`), ou la pull request le signale pour qu'un autre le fasse.
- Ouvrir une issue avant une grosse modification.

## English

Most helpful: failed cases (exact brief, agent, model, screenshots), new tells with two unrelated examples, model sites with a concrete quality to borrow, resources with a verified licence. Rules: nothing invented (verified sources), methods not styles, keep `SKILL.md` under 10 KB, measure behaviour changes on `evals/`, and mirror changes in both the French and English editions.
